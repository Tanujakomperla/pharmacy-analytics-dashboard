Prediction Model Information

Algorithm: Multiple Linear Regression

Input Features: Attendance, Study Hours Per Day and Internal Average

Target Variable: Final Marks

Training Method: The dataset is divided into training and testing data. The model learns the relationship between the input features and final marks using the training data.

Evaluation: R², MAE, MSE and RMSE are used to evaluate the prediction model.

Purpose: The model provides an estimated final mark based on the selected input features and the trained dataset.
