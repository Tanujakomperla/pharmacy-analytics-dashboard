Project Summary

Data Source: Pharmacy Student Performance Excel Dataset

Data Processing: Duplicate and missing records were removed before analysis.

Analysis: Descriptive statistics, subject-wise analysis and correlation analysis were performed.

Prediction: A multiple linear regression model was developed to estimate final marks using selected academic factors.

Purpose: The dashboard provides a single web-based interface for exploring student academic performance and statistical findings.
